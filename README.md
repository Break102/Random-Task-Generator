## Описание программы (кратко)
Генератор случайных задач — десктопное приложение на Python с графическим интерфейсом (Tkinter) для генерации случайных задач из предустановленного списка. Программа позволяет добавлять собственные задачи, фильтровать историю по категориям и сохранять данные между запусками в JSON‑файле.


### Возможности (что программа умеет делать)
* **Генерация случайных задач** из предустановленной базы с отображением названия задачи.
* **Добавление новых задач** с указанием:
    * названия задачи;
    * категории (учёба, спорт, работа, другое).
* **Фильтрация истории задач** по категориям через выпадающий список (включая опцию «все»).
* **Отображение истории выполненных/сгенерированных задач** в виде прокручиваемого списка с указанием названия и категории.
* **Сохранение истории** между запусками программы в файле `tasks.json`.
* **Валидация ввода** при добавлении задач (проверка на пустое поле).
* **Визуальная обратная связь** через всплывающие сообщения об ошибках или предупреждениях.
* **Автоматическое обновление** интерфейса при генерации, добавлении и фильтрации данных.

* **Поддержка предопределённого набора задач** для немедленного использования.

## Инструкция по запуску

### Требования для запуска программы
* Python 3.6 или выше.
* Стандартные библиотеки Python:
    * `tkinter` (GUI‑фреймворк);
    * `messagebox` (модуль tkinter для всплывающих окон);
    * `random` (генерация случайных чисел);
    * `json` (работа с JSON‑файлами);
    * `os` (проверка существования файла).

Программа не требует установки дополнительных пакетов — все зависимости входят в стандартную поставку Python.

2. Убедитесь, что у вас установлен Python 3.6+.
3. Откройте терминал или командную строку.
4. Перейдите в директорию, где сохранён файл программы.
